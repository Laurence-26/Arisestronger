# AriseStronger

Offline daily fitness quests inspired by *Solo Leveling*. Rank up from
**E-Rank Hunter** to **Shadow Monarch**. No account, no cloud — everything
lives in a SQLite database on this device.

## Features

- **Fully offline** — awaken a Hunter on-device. Multiple Hunters per phone.
- **Full workout per rank** (E → Shadow Monarch) with scaling targets.
- **Onboarding starting rank:** Beginner → E · Intermediate → C · Pro → B.
- **Custom exercises** (reps or timed, with a countdown timer).
- **Four tabs:** Quest · Program · Progress · Profile.
- **Plan tomorrow** extra work after you complete today.
- **First-miss grace**, then the **Penalty Zone**.
- **Local notifications** (morning quote + evening penalty warning).
- **JSON backup** export / import.

## Run

```
flutter pub get
flutter run
```

Play Store listing assets live in `store/`.
